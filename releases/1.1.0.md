### Upgrading Arches for HERs

1. You must be upgraded to at least Arches version 7.6.0 before proceeding. If you are on an earlier version, please refer to the upgrade process in the [Version 7.6.0 release notes](https://github.com/archesproject/arches/blob/dev/7.6.x/releases/7.6.0.md).

1. Upgrade to Arches for HERs 1.1.0

    ```sh
    pip install --upgrade arches_her==1.1.0
    ```

1. If you are running Arches on Apache, restart your server:

    ```sh
    sudo service apache2 reload
    ```

1. It is recommended that your system is reindexed to take advantage of the Arches v7.6.21 enablement of numeric search terms, and also to ensure that fixes to application-area mapping permissions are honored.

    Within your project reindex your database:

    - To run a full reindex of your database (delete and rebuild):

      ```sh
      python manage.py es reindex_database
      ```

    - To run a non-destructive reindex (the index is updated on a resource by resource basis):

      ```sh
      python manage.py es index_database --clear_index false
      ```
