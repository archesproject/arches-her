### Upgrading Arches for HERs

1. You must be upgraded to at least Arches version 7.6.0 before proceeding. If you are on an earlier version, please refer to the upgrade process in the [Version 7.6.0 release notes](https://github.com/archesproject/arches/blob/dev/7.6.x/releases/7.6.0.md).

1. Upgrade to Arches for HERs 1.1.1

    ```sh
    pip install --upgrade arches_her==1.1.1
    ```

1. If you are running Arches on Apache, restart your server:

    ```sh
    sudo service apache2 reload
    ```
