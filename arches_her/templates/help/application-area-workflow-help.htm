{% trans "Application Area Workflow" %}

This workflow enables users to record an area that may be re-developed or newly built.

Required Information
  • Application Area Name
  • Mapped Location (Geospatial Coordinates and/or Feature Shape)
Optional Information
  • Location Description (and Description Type)
  • Associated Monument, Area or Artefact
  • Area Description (and Description Type)
  • Area Designations (and Description Type)
Workflow Outcomes

Completion of this workflow will create a new Application Area resource instance.
