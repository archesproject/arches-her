{% trans "Consultation Workflow" %}

This workflow enables users to record advice on potential work related to an application area.

Required Information
  • Consultation Location (includes Geospatial Coordinates and Related Application Area)
  • Log and Target Dates
  • Consultation Type
  • Application Proposal Description
Optional Information
  • Application Type
  • Development Type
  • Contested Heritage
  • Application Reference Numbers
    • Reference
    • Reference Type
    • Agency
  • Associated Proposal File(s)
  • Contacts
    • Planning Officer
    • Planning Body
    • Consulting Contact
    • Casework Officer
    • Agent
    • Owner
    • Applicant
Workflow Outcomes

Completion of this workflow will create a new consultation resource instance.
